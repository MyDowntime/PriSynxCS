# PriSynx - CloudStream repository

Aggiungi questo URL in CloudStream > Estensioni > Aggiungi repository:

    https://raw.githubusercontent.com/MyDowntime/PriSynxCS/main/main.json

Questo branch contiene solo gli artifact per CloudStream (nessun sorgente):

- `main.json` - manifest del repository (punta a `plugins.json`)
- `plugins.json` - elenco delle 17 estensioni
- 17 file `.cs3`, una estensione separata per provider:
  Altadefinizione, AnimeSaturn, AnimeUnity, AnimeWorld, CB01, DualSync,
  Eurostreaming, Filmez, Guardoserie, IlCorsaroViola, MovyITA, OnlineSerieTV,
  PaCC, RaiPlay, RealTime, Toonitalia, VixSrc
- `assets/prisynx.png` - icona del repository
